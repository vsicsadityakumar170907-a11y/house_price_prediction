# Kanpur House Price Prediction

Practice project using a linear regression model written with Python's standard library.

## Important
The dataset is synthetic. Predictions are for learning only and are not real property valuations.

## Run the project
1. Explore data: `python .\01_explore_data.py`
2. Split data: `python .\02_split_data.py`
3. Prepare features: `python .\03_prepare_features.py`
4. Train and evaluate: `python .\04_train_model.py`
5. Predict interactively: `python .\06_interactive_predict.py`

The training script creates `model.json`. Run it again whenever you regenerate the prepared data.
